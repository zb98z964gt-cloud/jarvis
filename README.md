# JARVIS

Türkçe sesli yapay zekâ asistanı (PWA).

1. GitHub'da yeni bir repo aç (ör. `jarvis`), bu dosyaların hepsini yükle.
2. Settings → Pages → Branch: `main`, klasör `/ (root)` → Save.
3. iPhone'da Safari ile `https://KULLANICIADIN.github.io/jarvis/` adresini aç.
4. Paylaş → Ana Ekrana Ekle.
5. Sağ üstteki ⚙ ile Anthropic API anahtarını gir.
